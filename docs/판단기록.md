## 1. 사건에는 분야 사전(넓은 말)을 안 쓴다

| | |
|---|---|
| 정한 것 | 결과 ↔ 사건 연결은 **결과 노드가 직접 정한 좁은 핵심어**만 쓴다 |
| 왜 | 법안 이름은 「○○법 일부개정법률안」 이라 넓은 말이 잘 맞는다. 사건 이름은 「손해배상(기)」·「부당이득금」 이라 넓은 말을 대면 무관한 것이 무더기로 온다 |
| 실측 | 넓은 말 21,016건 → 사건 노드 19,148개. 좁은 말 4,214건 → 10,538개 |
| 바꾸는 자리 | `tools/link-case.mjs` 의 `r.wide = r.keys` |

## 2. 판례는 `search=3`(참조조문)으로만 받는다

| | |
|---|---|
| 정한 것 | 본문 검색(`search=2`)을 안 쓴다 |
| 왜 | '중대재해' 로 793건이 오는데 사건명이 「단체교섭청구의소」다. 본문에 그 말이 스쳐 간 것뿐이다 |
| 실측 | `search=3` 표본 12건을 상세까지 받아 **12/12 전부** 참조조문에 그 법이 있었다 |
| 바꾸는 자리 | `tools/collect-prec.mjs` 의 `search: 3` |

## 3. 헌재는 "이을 수 있는 것" 부터 받는다 — 중요도로 고르지 않는다

| | |
|---|---|
| 정한 것 | ① 사건명에 지도의 법 이름이 든 것 ② 그다음 최근 것 |
| 왜 | "중요한 사건" 을 고르면 그게 우리 판단이다. **연결 가능성과 시간**은 사실이다 |
| 실측 | 1,000건 받는 데 3,567번 시도했다 — 상세에 내용이 있는 것이 28%뿐이다(지정재판부 각하) |
| 바꾸는 자리 | `tools/collect-detc.mjs` 의 `hit`/`rest` 정렬 |

## 4. 판시사항에 이름이 섞일 수 있으면 **통째로 버린다**

| | |
|---|---|
| 정한 것 | `[당사자]`·`대리인`·`변호사` 가 있으면 그 판시사항을 안 쓴다 |
| 왜 | "판시사항엔 이름이 없다" 고 넘겨짚었는데 검사 47 이 진짜를 잡았다 — `국선대리인 변호사 송한사(사임)` |
| 왜 오려내지 않나 | 오려내다 놓치면 이름이 지도에 올라간다. **남기는 쪽이 아니라 버리는 쪽으로 기운다** |
| 실측 | 108개를 버렸다 |
| 바꾸는 자리 | `tools/link-case.mjs` 의 `NAME_RISK` |

## 5. KOSIS 거르는 기준 세 가지

| 기준 | 왜 |
|---|---|
| **연도별 10년 이상** | 결과 노드는 "왜 이렇게 됐나" 를 묻는 자리다. 3~4년짜리는 우연을 추세로 읽게 만든다 |
| **전국 단위만** | 시도별·시군구별을 넣으면 「쌀 생산량 시도별」 같은 것이 수만 개가 된다. 지역 이야기는 지역 지도의 몫이다 |
| **사람 생활에 닿는 것** | `db/kosis_want.json` 의 검색어 50개로 한정한다 |

셋 다 **편집 판단이다.** 그래서 코드가 아니라 파일과 이 문서에 적어 사람이 바꿀 수 있게 뒀다.
`keys` 는 통계표 이름을 쪼개서 뽑되 **창고의 공포 법안 18,158건과 대조해 3건 미만이면 버린다** —
지어낸 말이 조용히 0건이 되는 것을 만들 때 막는다.
`cats` 는 우리가 정하지 않고 **그 핵심어가 걸린 법안의 소관위**를 세어 정한다.

## 6. 정렬은 세 층 — '사건을 법안 위에' 는 안 한다

1. 손으로 이었다 → 2. 조문이 가리켰다 → 3. 이름·핵심어가 맞았다. 같은 층 안에서는 시간순.

층은 **근거가 어떻게 만들어졌는지**라 사실이다. 반면 "사람들이 사건을 더 궁금해한다" 는
우리 추측이다. 그건 근거가 아니라 취향이라 안 넣었다.

## 7. 첫 화면 — 노드는 다 그리고 이름표만 제한한다

이름표를 붙일 100개는 **이어진 선의 수 · 종류별 몫 · id 순**으로 고른다.
'화면 가운데에 가까운 것' 은 안 쓴다 — 카메라를 움직일 때마다 바뀌어
'지금 보고 있는 곳' 이라는 우연이 기준이 된다.
진영은 기준에 안 넣고 검사 46 이 분포를 띄운다.

## 8. 고리 반지름 ROUT = 1500

사건 1만 개가 들어오자 1050 에서 6/9 연대가 넘쳤다(최대 138%).
1300 이면 0/9 이지만 최대 90% 라 다음 수집 한 번에 다시 넘친다. 1500 은 67% 다.

## 12. 카드에서 '이 법이 하려던 것 · 남은 문제' 를 따로 두지 않았다

제목이 판단을 부른다는 지적이 맞다. 그래서 이름을 바꾸는 대신 **자리를 없앴다** —
`제1조(목적)` 를 옮긴 '무슨 법인지' 가 곧 '하려던 것' 이고, 그것을 제목 바로 아래
노란 글씨로 올렸다. 자동으로 들어온 법에는 `limit`(남은 문제)이 없으므로
빈 칸을 만들지 않았다. **빈 칸을 만들고 "아직 정리하지 못했습니다" 로 채우면
그 칸이 매 카드마다 반복되어 정작 읽을 것을 밀어낸다.**
손으로 넣은 법의 `limit` 은 지금도 그대로 나온다.

## 13. 종류는 **모양**으로 가른다 — 색은 이미 진영이 쓰고 있다

색은 파랑=민주 계열, 빨강=국민의힘 계열, 금=결과다.
법·헌재결정·판례는 **진영이 없다.** 거기에 색을 더 만들면 두 축이 섞여
"회색은 무슨 뜻이냐" 가 된다. 그래서 다른 축인 모양을 썼다.

| 종류 | 모양 |
|---|---|
| 결과 숫자 | 큰 원 (금색) |
| 법·정책 | 가로로 누운 사각형 — 법은 글이다 |
| 헌법재판소 결정 | 삼각형 |
| 법원 판례 · 사건 | 마름모 |
| 사람·정당·기관 | 원 |

**채움/빔은 그대로 뒀다** — 자동으로 들어온 것과 사람이 확인한 것의 구분이라
모양과 다른 뜻이다. 두 가지를 한 번에 읽을 수 있다.

처음에 사각형을 1.25×0.95 로 만들었더니 **r=7px 인 법 노드가 화면에서 원처럼 보였다.**
격자에 하나씩 크게 그려 눈으로 보고서야 알았다. 1.55×0.78 로 눕혔다.

**그리고 모양을 만들었으면 그 뜻을 어딘가에 적어야 한다.** '보는 법' 에 범례를 넣었다 —
안 적으면 보는 사람에게는 그냥 다른 그림일 뿐이다.
그때 `open` 을 붙였다가 검사 27 이 "서랍은 접힌 채 시작해야 한다" 로 FAIL 을 냈다.
