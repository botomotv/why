# 결과 소스 조사 — KOSIS (2026-08-26)

결과 노드가 19개뿐이고 그중 8개가 안보·외국인·중국에 쏠려 있다.
**결과 숫자가 이 지도의 성장 단위다.** 법안 수가 아니다.

## 지금 상태 — 인증키가 없어 실측을 못 했다

엔드포인트가 살아 있는 것은 확인했다.

```
https://kosis.kr/openapi/statisticsList.do?...&apiKey=TEST
  → {"err":"11","errMsg":"유효하지않은 인증KEY입니다."}
```

주소와 파라미터 모양은 맞고 **키만 있으면 된다.**
`tools/probe-kosis.mjs` 를 만들어 뒀다.

```bash
read -s KOSIS_KEY && export KOSIS_KEY && node tools/probe-kosis.mjs
```

키는 화면에 안 찍히고 이 셸에만 남는다. 창고에도 저장하지 않는다.

## 탐침이 확인할 것

1. **통계표 목록** (`statisticsList.do`) — 무엇을 받을 수 있나, 몇 건인가
2. **검색** (`statisticsSearch.do`) — `docs/다음단계.md` 의 후보 목록이 실제로 검색되나.
   `합계출산율 · 최저임금 · 자살률 · 청년 실업률 · 가계부채 · 아파트 매매가격 ·
   비정규직 · 고독사 · 사교육비 · 지역소멸` 열 개를 실제 검색어로 넣어 둔다
3. **시계열** (`Param/statisticsParameterData.do`) — `orgId`·`tblId`·`itmId`·`objL1`·
   `prdSe`·`startPrdDe`·`endPrdDe` 로 연도별 값이 오는가
4. **메타** (`statisticsExplData.do`) — 갱신 주기·출처가 있는가

**응답 필드 이름은 추측하지 않는다.** 받아서 그대로 찍게 해 뒀다.

## 결과 노드로 쓰려면 셋이 필요하다

| | 왜 |
|---|---|
| **시계열** | 한 시점 값만으로는 "왜 이렇게 됐나" 를 못 묻는다. 꺾이는 지점이 있어야 질문이 생긴다 |
| **원자료 링크** | 규칙 7. 출처 없는 노드는 안 넣는다 |
| **갱신 주기** | 한 번 받고 끝나면 지도가 늙는다. 언제 다시 받아야 하는지 알아야 한다 |

셋 중 하나라도 없으면 e-나라지표를 같이 봐야 한다.
e-나라지표는 지표별로 '작성 주기'와 '통계표 링크'를 따로 주므로 보완재가 된다.
