# 사건과 처벌

법원이 확정한 형벌을 지도에 올린다. **정치·정책과 성격이 다르다** —
누가 밀어붙였느냐가 아니라 재판부가 무엇을 선고했느냐다.

## 색 — 판례의 틸(#3FA9A6)을 그대로 쓴다

**새 색을 만들지 않는다.** 형량은 판례에서 나오므로 이 분야의 노드는 판례다.
색을 따로 주면 '판례와 다른 무엇' 이라는 없는 구별이 생긴다.

진영 축과는 이미 떨어져 있다:

| | 색 | 파랑과의 색상차 | 빨강과의 색상차 |
|---|---|---:|---:|
| 판례·사건과 처벌 | `#3FA9A6` | 60° | 150° |
| blue(민주 계열) | `#5B9BE5` | — | |
| red(국힘 계열) | `#E2635A` | | — |

「이 판결은 어느 편」 이라는 뜻이 생기지 않는다.

## 사건 목록은 이 형식으로 받는다

```json
{ "cases": [
  { "id":      "c_nth",
    "lab":     "짧은 사건 이름",
    "yr":      "2020",
    "charge":  "아동·청소년의성보호에관한법률위반 등",
    "caseNo":  "2024고합637",     ← 형량이 적힌 심급. 이것이 있어야 형량이 나온다
    "court":   "서울남부지방법원",
    "finalNo": "2025도1234",      ← 확정을 확인할 대법원 사건번호 (규칙 1)
    "why":     "사건번호를 어디서 확인했는지" } ]}
```

### 왜 사건번호가 필요한가

**「사건 이름 + 시기 + 죄명」 만으로는 못 찾는다.** 이유가 셋이다.

**① 판례의 `사건명` 은 죄명이지 사건 이름이 아니다.**

```
아동·청소년의성보호에관한법률위반(성착취물제작·배포등)
[인정된죄명:성폭력범죄의처벌등에관한특례법위반(허위영상물편집·반포등)]…
```

「n번방」·「신림동」 같은 말은 어디에도 없다. 언론이 붙인 이름이고 재판부는 안 쓴다.

**② 죄명으로 좁혀도 수백 건이고, 그 안에서 가릴 방법이 없다.**

| 죄명 | 전체 | 그중 1심(지방법원) |
|---|---:|---:|
| 아동·청소년의성보호 | 125 | **30** |
| 살인 | 504 | **36** |
| 업무상과실치사 | 226 | **54** |
| 중대재해 | 8 | **5** |

가릴 단서는 피고인 이름·사실관계인데 **둘 다 규칙 8 이 금지한다.**
우리가 안 담기로 한 바로 그 정보가 있어야 특정이 된다.

**③ 형량이 있는 심급이 드물다.**
판례 65,240건이 대법원인데 대법원 주문은 「상고를 기각한다」 뿐이다.
형량은 1심·항소심에 있고 그건 표의 4% 남짓이다.

### 사건번호를 모를 때

```bash
node tools/sentence.mjs --find 살인 2024
```

죄명·연도로 후보를 좁혀 보여준다. **고르는 것은 사람이다.**
우리가 고르면 그건 추측이고, 틀리면 엉뚱한 사람의 형량을 올리게 된다.

## 형량은 주문(主文)에서만 뽑는다

법제처 `판례내용` 의 구조:

```
【피 고 인】 피고인
【검  사】 차병곤 외 1인          ← 실명
【변 호 인】 변호사 홍푸른 외 1인   ← 실명
【주  문】 피고인을 징역 5년에 처한다. 압수된 과도 1자루…
【이  유】【범죄사실】 …           ← 실명 + 피해 내용
```

**전문을 담지 않는다.** `【주 문】` ~ `【이 유】` 구간만 잘라내고
그 안에서 형벌 문장만 고른다. 나머지는 그 자리에서 버린다.

- **범죄사실** — 실명이 있고, 피해 내용을 자세히 적지 않는다는 약속도 있다
- **압수물 목록** (「과도 1자루」) — 형량이 아니라 사건 묘사다
- **「이 죄는 보통 몇 년」** — 평균은 만들지 않는다. 주문에 적힌 그대로만

### 꼴을 쫓지 않고 문장으로 쪼갠다

처음엔 「피고인을 징역 N년에 처한다」 같은 **꼴을 정규식으로** 잡았다.
30건 중 5건을 놓쳤다 — 주문의 표현이 생각보다 다양하다:

```
피고인 1을 징역 10개월에, 피고인 2를 징역 5개월에 각 처한다   여럿을 한 문장에
피고인을 징역 장기 8년, 단기 5년에 처한다                     부정기형(소년범)
피고인의 항소를 기각한다                                     항소심
나머지 상고 및 피고인 2의 상고를 각 기각한다                  일부만 기각
원심판결 중 무죄 부분을 파기하고 … 환송한다                   일부 파기
```

**꼴을 늘려 쫓아가면 끝이 없다.** 그래서 문장 단위로 쪼개고 형벌 낱말이 든 문장을 담는다.
이름 검사는 문장마다 하므로 안전은 그대로다.

## 지키는 것

- **확정 판결만.** 재판 중은 안 올린다 (규칙 1). `finalNo` 로 확인한다
- **사람 이름은 어떤 형태로도 안 올린다** (규칙 8). 이름이 섞인 문장은 **통째로 버린다** —
  오려내다 놓치면 이름이 지도에 올라간다. 남기는 쪽이 아니라 버리는 쪽으로 기운다
- **익명 마스크(○)가 있으면 그 자리가 사람 이름이다.** 「청구인 김○현」처럼 성 한 글자만
  남아도 사건번호와 함께 있으면 누구인지 좁혀진다. 그 문장도 버린다
