# 왜

한국 정치·정책의 인과관계를 지도로 보여주는 웹사이트.

**"이 숫자가 왜 이렇게 됐나"를 결과에서 거꾸로 추적한다.**

합계출산율 0.72명. 연금 기금 소진 2071년. 집값 5.36% 상승.
이 숫자들이 출발점이다. 거기서 거꾸로 올라가며 어떤 법과 결정이 있었는지,
그리고 **그게 정말 원인인지 아닌지**를 함께 보여준다.

무료 공개. 광고·후원·구독 없음. **신뢰가 유일한 자산이다.**

---

## 왜 만드나

정치 이야기는 대개 두 가지 중 하나다. 누가 나쁜 놈인지 가리거나, 너무 복잡해서 포기하거나.

그 사이가 비어 있다. **"이 숫자는 왜 이렇게 됐나"** 를 사실만으로 따라가는 지도.
누가 옳은지 말하지 않고, 무슨 일이 있었는지 출처와 함께 보여주고,
**그게 원인이라고 단정할 수 없는 이유까지 같이 적는다.**

판단은 보는 사람이 한다. 우리가 하는 일은 판단할 재료를 정직하게 놓는 것이다.

## 절대 규칙 7개

전문과 이유는 [docs/규칙.md](docs/규칙.md)에 있다.

1. **확정된 공식 기록만 싣는다.** 수사 중인 의혹은 절대 넣지 않는다.
   전과는 중앙선관위가 공표한 확정 판결만, 반드시 본인 해명과 함께.
2. **확인 안 된 숫자는 지어내지 않는다.** "확인 중"으로 비워둔다.
   링크는 실제로 열리는지 확인한 것만 넣는다.
3. **"재임 중"과 "밀어붙임"은 다르다.** 그 시기 대통령이었다는 것과
   그 사람이 그 법을 만들었다는 건 전혀 다른 사실이다.
   대통령 관계는 공포일자 × 재임표 계산으로만 만든다.
4. **시간 순서를 인과관계로 단정하지 않는다.** 결과 카드에 교란 요인을 함께 적는다.
5. **법안마다 "남은 문제·비판" 칸을 채운다.** 한쪽 진영에만 붙이지 않는다.
6. **공공누리·퍼블릭도메인 사진만.** 재가공도 안 된다.
   `photoLicense`가 확인 안 되면 실루엣으로 떨어뜨린다.
7. **모든 노드에 출처를 표기한다.**

### 규칙은 프롬프트가 아니라 검사가 지킨다

사람이 지키는 규칙은 언젠가 깨진다. 그래서 강제는 전부 [test/check.cjs](test/check.cjs)에 있다.
`npm test`가 FAIL을 내면 커밋하지 않는다.

그리고 **그 검사 자체를 의심한다.** 이 프로젝트에서 "통과했다"가 세 번 거짓이었다 —
`exit(0)` 하드코딩, 이름표 대신 원만 재던 겹침 검사, 한글 폭을 절반으로 재던 `measureText`.
자세한 건 [CLAUDE.md](CLAUDE.md)의 "검사를 검사한다"에 적어뒀다.

CSS에도 규칙이 하나 있다. **미디어쿼리는 항상 `<style>` 맨 끝에 모으고 그 뒤에 일반 규칙을 쓰지 않는다.**
같은 특정도면 나중 선언이 이겨서 반응형이 조용히 무력화되기 때문이다.
이것도 세 번 났고 검사가 강제한다.

## 로컬에서 띄우기

Node.js가 있어야 한다. ([nodejs.org](https://nodejs.org) — LTS 버전)

**1. 처음 한 번만**

```bash
npm install
```

**2. 브라우저로 보기**

`index.html`은 파일 하나로 끝나는 정적 페이지다. **더블클릭해서 바로 열어도 동작한다.**

로컬 서버로 띄우고 싶으면:

```bash
python3 -m http.server 4173
```

그다음 브라우저에서 `http://localhost:4173/index.html` 을 연다.
멈출 때는 터미널에서 `Ctrl + C`.

**3. 검사 돌리기**

```bash
npm test
```

`jsdom`으로 실제 페이지를 띄워서 검사한다. 30초쯤 걸린다.
해상도 **412(폰) · 840(폴드) · 1440 · 1920** 을 모두 확인한다.

검사하는 것: 끊긴 링크 · 고립 노드 · 재임 오분류 · 원인 없는 결과 노드 ·
출처 표기 · 법안 `limit` 칸 · 사진 라이선스 · 진영 분포 · `official2` 링크 생존 ·
좌표 · 정착 · 점 겹침 · **이름표 겹침 · 화면상 글자 크기**

`FAIL`이 하나라도 있으면 종료 코드 1로 끝난다. **통과한 것만 커밋한다.**

docs/배포.md        Cloudflare Pages 배포 절차

데이터 구조는 **노드 · 관계 · 역할** 세 가지뿐이다. 나라가 바뀌어도 틀은 같다.

- **노드** `{id, t, side, lab, src, ...}` — `t`는 `bill`(법안) / `result`(결과) / `person` 등
- **관계** `[from, to, label, role, sentence, evidence]` —
  `role`은 `lead`(밀어붙임) / `term`(그때 정권) 등. `evidence`가 있어야 인과로 인정된다

현재 규모: 노드 231개(선언 164 + 런타임 파생 67) · 관계 307개 · 분야 19개 ·
법안 26개 · 결과 19개.

## 아직 안 된 것

숨길 이유가 없다. 지금 상태는 이렇다.

### 결과 노드가 19개뿐이다 — 이게 진짜 병목

사이트 이름이 '왜'다. 방문자는 **결과 숫자에서 출발한다.**
그러니 **입구 개수 = 결과 노드 개수**다. 지금 입구가 19개다.
법안을 26개에서 50개로 늘려도 들어올 문은 그대로다.

손으로 채우지 않는다. 결과 숫자는 대부분 KOSIS 쪽이고 **인증키가 아직 없다.**
수집기가 먼저다. → [docs/다음단계.md](docs/다음단계.md)

### 이름표가 겹친다 — 전 해상도 280~290쌍

노드 이름표끼리 서로 위에 겹쳐 그려진다. 붐비는 구역은 글자가 뭉개진다.
겹침을 피하는 로직(우선순위가 낮은 이름표를 숨기기)이 아직 없다.

**필터를 걸면 대부분 사라진다.** 분야 하나를 고르면 겹침이 290쌍 → 2쌍이 된다.
"전체"로 볼 때만 심각하다.

### 큰 화면에서 글자가 작다 — 1440에서 6.3px, 1920에서 8px

이름표가 카메라 배율에 곱해져 그려진다(`12px × cam.s`). 읽을 수 있는 하한의 절반이다.
폰·폴드는 배율을 1.0으로 고정해 12px을 확보했지만 데스크톱은 아직이다.

### 진영 분포가 기울어 있다 — 진보 93 : 보수 55 (기울기 25.7%)

규칙 5와 부딪히는 지점이다. 국회 발의·표결 데이터가 아직 안 들어와서 생긴 구멍이다.
**손으로 맞추지 않는다.** 손으로 맞추면 균형이 아니라 연출이다.
`npm test`가 매번 이 수치를 막대로 출력해서 눈앞에 띄운다.

### 그 밖에

- 법안 4개(`b6` `b7` `b9` `b11`)의 `limit`(남은 문제·비판) 칸이 비어 있다 — WARN
- `official2` 원자료 링크가 붙은 노드가 2개뿐이다
- API 수집기가 없다 (인증키 없음)
- 실기기 테스트를 못 했다. 터치 제스처(두 손가락 확대, 드래그) 미확인

## 로드맵

한국판 완성 → 미국 · 일본 확장 → 다국어 지원.
데이터 구조가 나라와 무관하게 같아서, 창고를 분리하면 `country` 열 하나로 갈린다.

**콘텐츠(어느 나라 정치)와 언어(무슨 말로 읽나)는 별개다.** 3개국 × 3개 언어 = 9칸이다.
무엇이 깨지고 무엇을 번역이 아니라 인용해야 하는지는 [docs/다국어.md](docs/다국어.md)에 미리 적어뒀다.
**아직 착수하지 않는다 — 결과 노드 19개가 먼저다.**

순서: **배포 → 렌더링 분리 → API 수집기.**
쪼개기 전에 배포하고, 배포한 것으로 무엇이 문제인지 확인한 다음 쪼갠다.
