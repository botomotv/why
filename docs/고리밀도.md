# 전체 보기에서 노드가 한쪽에 뭉친다

**C안으로 고쳤다.** 아래 "고친 결과" 를 볼 것. 앞부분은 왜 이 방법을 골랐는지의 기록이다.

---

## 원인 — 각도가 아니라 반지름이다

### 각도는 고르다

12방향으로 나눠 세어봤다.

```
12 / 19 / 13 / 12 / 13 / 10 / 12 / 14 / 14 / 20 / 20 / 12
```

최다 20, 최소 10. 황금각(2.39996 rad)이 제 일을 하고 있다. **여기는 문제가 없다.**

### 반지름이 압축돼 있다

```
RY0 1943 · RY1 2027   →  84년
RIN  150 · ROUT  830  →  680px
                          1년당 8.1px
```

**노드 지름은 12~74px 이다.** 즉 **한 노드가 1.5년에서 9년치 반지름을 차지한다.**
고리는 그림으로만 있고, 물리적으로는 인접 연도가 서로 겹친다.

### 그래서 최근이 넘친다

고리 넓이 대비 노드가 차지하는 면적(채움률):

| 연대 | 개수 | 채움률 |
|---|---:|---:|
| 1940년대 | 4 | 19% |
| 1950년대 | 2 | **6%** |
| 1960년대 | 6 | 14% |
| 1970년대 | 9 | 29% |
| 1980년대 | 12 | 27% |
| 1990년대 | 14 | 22% |
| 2000년대 | 30 | 46% |
| 2010년대 | 24 | 37% |
| **2020년대** | **70** | **205% ← 넘침** |

**31~32배 차이다.** 2020년대는 고리 넓이의 **두 배**를 노드가 요구한다.
들어갈 수 없으니 서로 밀어내고, 밀려난 것들이 한쪽에 뭉친다.

`timeOut=true` 라 최근이 바깥이다. 바깥 고리가 터져 있는 상태다.

**검사 22번이 매 실행마다 이 표를 출력한다.**

---

## 왜 이렇게 됐나 — 데이터가 최근에 몰려 있다

노드 171개 중 **70개(41%)가 2020년대**다. 1950년대는 2개다.
이건 버그가 아니라 데이터의 실제 모습이다. 그리고 **더 심해진다** —
수집기가 22대 국회(2024~) 자료를 넣으면 최근 쪽이 계속 불어난다.

**그래서 지금 고치지 않으면 데이터를 넣을수록 나빠진다.**

---

## 방법 — 네 가지를 같은 자로 쟀다

고리 폭을 어떻게 나눌지의 문제다. **각도는 손대지 않는다.**

| | 최대 채움률 | 최소 | 차이 | 넘치는 연대 |
|---|---:|---:|---:|---:|
| **지금** · 반지름 = 연도 (선형) | **205%** | 6% | 32배 | 1개 |
| **B** · 고리 폭을 필요 면적에 비례 | **47%** | 47% | **1배** | 0개 |
| **C** · 고리 폭을 노드 개수에 비례 | 61% | 22% | 3배 | 0개 |
| **D** · 연도와 면적을 반씩 섞기 | 72% | 12% | 6배 | 0개 |

### 무엇을 잃나 — 이게 판단의 핵심이다

세 안 모두 **순서는 지킨다.** 안쪽이 최근, 바깥이 과거(또는 그 반대)는 그대로다.
잃는 것은 **비례**다.

```
지금  화면상 거리 2배  =  실제로 2배 오래전
B·C·D  화면상 거리 2배  ≠  2배 오래전
```

**이건 진짜 손실이다.** 부채꼴 작업에서 "각도는 뜻이 없고 반지름만 연도다" 라고
못 박았는데, 그 반지름의 뜻을 약하게 만드는 일이다.

다만 **완전히 잃는 것은 아니다.**
- 고리에 **연도 숫자가 그려져 있다**(`1950` `1960` …). 그 숫자는 `radY(y)` 로
  같이 움직이므로 **어느 안을 쓰든 계속 정확하다.** 보는 사람은 눈금을 읽을 수 있다
- 로그 눈금 그래프와 같은 성격이다 — 눈금이 있으면 비선형도 읽을 수 있다

### 제안 — **C안**

`B` 는 완벽하게 고르지만 **연도 감각을 가장 많이 지운다.**
`D` 는 절충인데 최대 72%로 여유가 적고, 데이터가 늘면 다시 넘친다.

**`C` 를 고른 이유:**
- 넘치는 연대 0개 · 최대 61% 로 여유가 있다
- 노드 **개수**에 비례하므로 데이터가 늘어도 자동으로 재배분된다.
  `B`(면적 비례)는 노드 크기까지 따라가서 큰 결과 노드 하나에 고리가 휘둘린다
- 규칙이 한 줄로 설명된다 — **"그 시기에 일이 많으면 고리가 넓어진다"**

### 반드시 같이 해야 할 것

1. **화면에 밝힌다.** "고리 간격은 실제 시간 간격과 다릅니다 — 일이 많은 시기가 넓습니다"
   한 줄. 밝히지 않으면 우리가 시간을 왜곡해 보여주는 게 된다
2. **연도 눈금을 더 촘촘히.** 지금은 10년 단위인데, 넓어진 구간에는 5년 단위로
3. **검사 22번을 판정으로 바꾼다.** 지금은 출력만 한다.
   고친 뒤에는 **채움률 100% 초과 시 FAIL** 로 올린다
4. **실패 주입** — 일부러 한 연대에 노드를 몰아넣고 검사가 FAIL 하는지 본다

---

## 안 하는 것

- **각도를 건드리는 것.** 이미 고르다. 만져봐야 얻는 게 없다
- **RIN/ROUT 를 키우는 것.** 화면은 그대로인데 배율만 내려가 이름표가 죽는다
- **노드 크기를 줄이는 것.** 읽히는 하한이 12.5px 이라 여유가 없다

## 고친 결과

### 채움률

| 연대 | 전 | 후 |
|---|---:|---:|
| 2020년대 | **205% (넘침)** | **69%** |
| 1950년대 | 6% | 17% |
| **최대/최소 차이** | **32배** | **4배** |
| 넘치는 연대 | 1개 | **0개** |

첫 화면 이름표도 늘었다 — 1440×900 에서 **75/171개**.

### 어떻게

`radY(y)` 를 연도 선형에서 **누적 항목 수 비례**로 바꿨다.
원의 넓이는 반지름 제곱에 비례하므로 누적 비율의 제곱근을 쓴다.

```js
function radY(y){
  var t=ringT(y);                 /* 그 해까지의 누적 항목 비율 0~1 */
  t=1-t; if(timeOut)t=1-t;
  return Math.sqrt(RIN*RIN + t*(ROUT*ROUT-RIN*RIN))
}
```

`ringT()` 는 연도별 개수 표를 만들어 누적 비율을 내고, 사이 값은 선형 보간한다.
표는 `A`(보이는 노드)가 바뀔 때만 다시 만든다 — 필터를 걸면 고리도 그에 맞춰 재배분된다.

### 순서는 지킨다 — 검사 25번

**안쪽이 언제나 더 이른 때다.** 시간 방향을 뒤집으면 반대다.
`RY0~RY1` 84년을 1년 단위로 훑어 반지름이 단조로운지 본다.

```
25. 반지름 순서  timeIn   연도↑ 반지름↓ · 830→150px · 어긋난 곳 0/84
25. 반지름 순서  timeOut  연도↑ 반지름↑ · 150→830px · 어긋난 곳 0/84
```

1985~1987 반지름을 90px 틀어 넣었더니 두 방향 모두 FAIL 했다.

### 밝힌다 — 검사 25번이 강제

10년당 고리 폭이 **18~167px 로 9배** 벌어진다. 밝히지 않으면 시간을 왜곡해 보여주는 게 된다.

```
고리 간격은 실제 시간 간격과 다릅니다
일이 많았던 시기일수록 고리가 넓습니다 · 순서는 그대로입니다
```

**화면 좌표로 그린다.** 처음엔 고리 옆(월드 좌표)에 두었는데
확대·축소에 따라 화면 밖으로 나갔다. 워터마크와 같은 방식으로 왼쪽 위에 고정한다.

검사가 `fillText` 를 가로채 **실제로 그려지는지** 본다 (412px·1440px).
문구를 지우면 FAIL 한다. 워터마크 검사(16번)와 같은 방식이다.

전문은 왼쪽 패널 '시간 방향' 카드에 있다.

### 연도 눈금을 다시 만들었다

전에는 `[2025,2020,…,1995]` 만 하드코딩돼 있었다.
고리 폭이 시기마다 달라지니 **옛 고리가 좁아져 연도를 읽을 수 없게 된다.**
이제 **반지름 여유가 화면상 34px 이상 벌어질 때마다** 눈금을 그린다 —
촘촘한 쪽은 건너뛰고 넓은 쪽은 5년마다.

**눈금이 정확해야 비선형 간격을 읽을 수 있다.** 로그 눈금 그래프와 같은 이치다.

### 검사 22번을 FAIL 로 올렸다

수집기가 데이터를 넣으면 다시 넘칠 것이다. 그때 조용히 뭉치면 화면만 나빠지고 아무도 모른다.
고리 폭을 연도 선형으로 되돌려 넣었더니 `2020년대 189%` 로 FAIL 했다.
